# ladder21 で strict 勝利ケースが出た要因の深掘り (2026-06-16)

> 問い: ladder21 で held-out strict_v1 が初めて 3/64 (4.7%) に達した要因は何か。

## まず統計的な正直な前置き
held-out は n=64。ladder21 の strict_v1 は iter0-69 で {1,0,0,2,3,0,0,1}/64 と**振れている**。
最高 3/64=4.7% は単独では noise 範囲。**「strict を攻略した」ではない。** ただし過去 run と
比べると差があり、その差の要因は深掘りに値する。

## 過去 run との差 (事実)

### held-out strict_v1 の非0評価点の数
| run | strict非0だった評価点 | 最高 |
|---|---|---|
| ladder18 (修正前) | 3/4点 が 1/64 | 1/64 |
| **ladder21 (A+B+C)** | **4/8点 が非0、うち 2/64・3/64 を含む** | **3/64** |
| 他の大半 | 0 点 | 0/64 |

ladder21 は「**1勝を超える評価点 (2/64, 3/64) を出した初の run**」。1/64 は偶発でも、2-3/64
が複数回出るのは僅かに分布が上にずれた可能性を示唆 (確定はできない)。

### 決定的な事実: 弱体化strict (T0>0) の訓練win が全段で上昇

| T0 | ladder18 | **ladder21** | Δ |
|---|---|---|---|
| 200 | 0.698 | 0.733 | **+0.035** |
| 185 | 0.643 | 0.691 | **+0.048** |
| 155 | 0.529 | 0.602 | **+0.073** |
| 140 | 0.435 | 0.510 | **+0.076** |
| 110 | 0.271 | 0.329 | **+0.058** |
| 0 | 0.000 | 0.005 | +0.005 |

**全 T0 段で +0.03〜+0.08 の一様な底上げ** (T0=0 を除く)。これは noise でなく**系統的改善** —
ladder21 の3修正のうち held-out 評価点に依らない訓練側の指標で、明確に効いている。

## 要因の切り分け (どの修正が効いたか)

ladder21 は A+B+C を同時投入した (A/B規律上は単一の狙い「degenerate阻止」の表裏)。
訓練win の一様な底上げから、効いた要因を推定:

1. **C: no_op_bias 8.0→2.0 が主因と推定**。
   - replay診断で「agent は strict の3-4倍 fleet を乱発、87%が戦力不足」= no_op_bias=8 が
     「撃たない」を罰し過剰発射させていた。
   - C で発射圧を下げ「撃つべき時だけ撃つ」余地が出た → **無駄発射の戦力分散が減り、捕獲効率
     が上がった**。全 T0 段で一様に win が上がったのは、これが「序盤特有」でなく「fleet運用
     全般」の改善だから、と整合。aim修正 (ladder18) と相補的に効いた。

2. **B: adv_std_floor=0.1 が学習を安定化**。
   - 中盤段 (T0=110-155) の win 上昇幅が大きい (+0.06〜0.08)。これらは勝率が0.3-0.5 で
     advantage分散が小さめの段で、零分散ノイズ増幅の害が大きかった所。floor で安定し学習が
     乗った可能性。

3. **A: skip_update_if_no_win は今回ほぼ不発**。
   - T0=0 段が iter4 の1回しか来ず (win=0.005 で skip閾値 n_wins==0 に漏れた)。素strict段の
     entropy は依然崩壊 (11.7)。**A は閾値が甘く効いていない** = T0=0 の +0.005 は誤差。

## 結論: 「strict勝利ケース」の正体

- held-out 3/64 自体は noise 範囲だが、**背景に「弱体化strict 全段の訓練win 一様底上げ (+0.03-0.08)」
  という系統的改善**があり、その主因は **C (no_op_bias↓ による over-fire 是正)** と推定。
  aim修正 (ladder18) で「当てられる」ようになった上に、C で「無駄撃ちを減らした」ことで
  fleet運用が改善し、全体的に strict に対する地力が上がった。
- ただし **素strict (T0=0) の断崖は不変** — A が閾値の甘さで不発、T0=0 の訓練量も極小のまま。
  3/64 は「地力底上げの裾が held-out にわずかに漏れた」程度で、序盤攻略の本質的解決ではない。

## 次の調整への含意 (要因に基づく)
1. **C (no_op_bias) の効きが確認できた** → さらに下げる余地 (2.0→1.0 or 0) を単一A/Bで検証価値あり。
   over-fire 是正が地力に直結している。
2. **A を正しく効かせる**: skip閾値 `n_wins==0`→`win<0.05` + 素strict段を force_rung_low で
   強制照射 → T0=0 の訓練量を増やしつつ degenerate poison を防ぐ。断崖そのものを狙う。
3. 1 (地力) と 2 (序盤断崖) は別の軸。まず効果の確実な C深掘り or A修正のどちらかを単一で。
