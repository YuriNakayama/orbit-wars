## 概要

Tactical Heuristic（v1、スコア587.5）を大幅に発展させた**ミッション計画型ヒューリスティックエージェント**。単純なターゲット選択から脱し、複数ミッションタイプの統合スコアリングと精密な未来状態シミュレーションを実装している。

### モジュール構成

```
CONFIG          ← グローバルパラメータ（80行以上）

```

## ミッションシステム

### ミッションタイプ一覧

| タイプ | 概要 | スコア乗数 |
|--------|------|------------|
| **expand** | 中立星のキャプチャ | `SAFE/CONTESTED_NEUTRAL_VALUE_MULT` |
| **attack** | 敵星への攻撃 | `HOSTILE_TARGET_VALUE_MULT = 1.85` |
| **snipe** | 敵フリートと同ターン到着して横取り | `SNIPE_VALUE_MULT = 1.12` |
| **swarm** | 複数星から同時到着の集中攻撃 | `SWARM_VALUE_MULT = 1.05` |
| **reinforce** | 陥落危機の自軍星への援軍 | `REINFORCE_VALUE_MULT = 1.35` |
| **crash_exploit** | 4P時：敵フリートが太陽で消えた直後を狙う | `CRASH_EXPLOIT_VALUE_MULT = 1.18` |

### ミッションスコア計算式

```python
# 基本スコア
base = production * turns_profit
iw   = indirect_wealth(target, planets, player)  # 隣接価値（間接的利益）
value = base + iw * turns_profit * INDIRECT_VALUE_SCALE

# 状況補正
if is_enemy:   value *= HOSTILE_TARGET_VALUE_MULT
if is_snipe:   value *= SNIPE_VALUE_MULT
if is_comet:   value *= COMET_VALUE_MULT
if is_late:    value += target.ships * LATE_IMMEDIATE_SHIP_VALUE
if is_finishing and enemy: value *= FINISHING_HOSTILE_VALUE_MULT

# コスト
cost = ships_needed + turns * 0.55  # ATTACK_COST_TURN_WEIGHT
score = value / (cost + 1.0)
```

## `agent()` 関数のフロー

```
1. WorldStateを構築
2. ゲームフェーズを判定（early / opening / normal / late / very_late）
3. 各ミッション生成
   ├── build_expansion_missions()
   ├── build_attack_missions()
   ├── build_snipe_missions()
   ├── build_swarm_missions()
   ├── build_reinforcement_missions()
   └── build_crash_exploit_missions()  ← 4P only
4. 全ミッションをスコア降順にソート
5. リソース制約を満たしながら順次実行
   ├── available[src.id] -= send
   └── target_commitments[tgt.id] += send
6. Doomed星の退避
7. Rear expansion（後方余剰星からの拡張）
8. return moves
```
