## 評価・ランキングシステム

### 提出ルール
- 1日最大 **5エージェント**まで提出可能
- ランキングには最新 **2件**のみ追跡（最終提出として使用）
- リーダーボードには最高スコアのボットのみ表示

### スキルレーティング
各提出は **ガウス分布 N(μ, σ²)** でモデル化されたスキルレーティングを持つ。

- **μ**：推定スキル（初期値 μ₀ = 600）
- **σ**：推定の不確かさ（対戦を重ねると減少）

### レーティング更新
- 勝利 → μが上昇、相手のμが下降
- 引き分け → 双方のμが平均値に近づく
- 更新量は「期待値からのずれ」と「不確かさσ」に比例
- **スコア差はレーティング更新に影響しない**（勝敗のみ）

### バリデーション
提出後まず自分自身との対戦（Validation Episode）を実施。失敗した場合はエラーとしてフラグされ、ログをダウンロードしてデバッグ可能。

## ゲームルール

### ボード
- **100×100** の連続2D空間（左上が原点）
- **太陽**: 中心 (50, 50)、半径 10。太陽を通過するフリートは即時破壊
- **4折対称**: 全惑星・コメットは (x,y), (100-x,y), (x,100-y), (100-x,100-y) に対称配置

### 勝利条件
- **500ターン**終了時、または相手が全滅した時点で終了
- **最終スコア** = 自軍惑星の総艦数 + 飛行中フリートの総艦数
- 最大スコアのプレイヤーが勝利

## ゲームオブジェクト

### 惑星（Planet）

```
[id, owner, x, y, radius, ships, production]
```

| フィールド | 説明 |
|-----------|------|
| `owner` | プレイヤーID（0〜3）または `-1`（中立） |
| `radius` | `1 + ln(production)`（生産量が大きいほど物理的に大きい） |
| `production` | 1〜5（毎ターン所有者に艦を生成） |
| `ships` | 駐留艦数（初期値: 5〜99、低め寄り） |

#### 惑星の種類

| 種類 | 条件 | 挙動 |
|------|------|------|
| **軌道惑星** | `orbital_radius + planet_radius < 50` | 太陽の周りを一定角速度（0.025〜0.05 rad/turn）で公転 |
| **静止惑星** | 上記以外 | 動かない |

- マップ上に **20〜40惑星**（4グループ対称で 5〜10グループ）
- 静止グループ最低3つ、軌道グループ最低1つを保証
- **ホーム惑星**: ランダム選択されたグループ。2P時は対角、4P時は各象限に1つ。初期艦数10

### フリート（Fleet）

```
[id, owner, x, y, angle, from_planet_id, ships]
```

#### フリートの速度
```
speed = 1.0 + (maxSpeed - 1.0) × (log(ships) / log(1000))^1.5
```
- 1艦 → 速度 1.0
- ~500艦 → 速度 ~5.0
- ~1000艦 → 速度最大 6.0（大きいフリートほど速い）

#### フリートの消滅条件
- フィールド外に出た場合
- 太陽を通過した場合
- 惑星に衝突した場合 → **戦闘発生**

衝突判定は**連続的**（エンドポイントだけでなく移動線分全体をチェック）

### コメット

| 属性 | 値 |
|------|---|
| 出現タイミング | ターン 50, 150, 250, 350, 450 に4つ1グループで出現 |
| 半径 | 1.0（固定） |
| 生産量 | 1艦/ターン（所有時） |
| 初期艦数 | ランダム（低め寄り、グループ内で共通） |
| 速度 | デフォルト 4.0 units/turn |
| 消滅 | フィールド外に出ると艦ごと消滅 |

- `comet_planet_ids` フィールドで識別可能
- 通常惑星と同じルール（キャプチャ・生産・フリート発射・戦闘）に従う
- **コメット発射不可**: コメットが消える前のターンに発射は不可

## ターン順序

毎ターン、以下の順序で処理される：

1. **コメット消滅**: フィールド外に出たコメットを除去
2. **コメット出現**: 指定ターンに新グループをスポーン
3. **フリート発射**: 全プレイヤーのアクションを処理
4. **生産**: 所有惑星（コメット含む）が艦を生成
5. **フリート移動**: 全フリートを移動 → 範囲外・太陽・惑星衝突チェック
6. **惑星回転 & コメット移動**: 軌道惑星が回転、コメットが移動 → 惑星/コメットに捕捉されたフリートが戦闘キュー入り
7. **戦闘解決**: キューの全戦闘を解決

---

## 戦闘ルール

```
攻撃者を owner ごとにグループ化
  → 最大勢力 vs 第2勢力 → 差が生き残る
  → 生存攻撃者がいる場合:
      同 owner → 駐留艦に加算
      異 owner → 駐留艦と再戦 → 攻撃者が多ければ惑星を占領
  → 攻撃者が引き分け → 全員消滅
```

## 観測データ（Observation）

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `planets` | `[[id, owner, x, y, radius, ships, production], ...]` | コメット含む全惑星 |
| `fleets` | `[[id, owner, x, y, angle, from_planet_id, ships], ...]` | 全フリート |

| `comets` | `[{planet_ids, paths, path_index}, ...]` | コメットグループデータ（軌跡予測可能） |
| `comet_planet_ids` | `[int, ...]` | コメットの planet ID 一覧 |
| `remainingOverageTime` | `float` | 残オーバータイムバジェット（秒） |
